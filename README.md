# Portfolio Optimization with Mean-Variance Analysis

Building a diversified portfolio of 8 exchange-traded funds (US, developed and emerging equities, Treasuries, corporate bonds, gold, real estate) using modern portfolio theory, in Python (pandas, NumPy, matplotlib, yfinance).

**Status: in progress.**

## Progress
- [x] Step 1: Data download (2015-2025), daily returns, annualized return and volatility, return per unit of risk
- [ ] Step 2: Covariance and correlation matrices
- [ ] Step 3: Portfolio return and volatility
- [ ] Step 4: Random portfolio simulation
- [ ] Step 5: Minimum variance and maximum Sharpe ratio portfolios, efficient frontier
- [ ] Step 6: Comparison with a benchmark

## Key finding so far
Over 2015-2025, gold (GLD) delivered the best return per unit of risk (0.84), slightly ahead of US equities (SPY, 0.80), while long-term Treasuries (TLT) ranked last (0.02) after the 2022 interest rate hikes.

Data: Yahoo Finance, adjusted daily closing prices. Educational project.
